How a Simple Neural Network Works

The model in three layers

Give the model an image of a handwritten digit, and it predicts which digit it is. Here is the architecture:

import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Flatten(input_shape=(28, 28)),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(10, activation='softmax')
])

import tensorflow as tf

import loads a library, tensorflow is the machine learning library, and as tf is a shorter alias. We write tf.keras instead of tensorflow.keras.

model =

A Python variable that stores the network. You use it later to train, predict, and evaluate. Think of it as the name of the machine you are building.

tf.keras.Sequential([ ])

keras is TensorFlow's high-level API. Sequential() arranges layers one after another, inside a Python list.

Analogy: an assembly line. A product passes through one machine, then the next. Data passes through Sequential layers in order, which suits this model because it follows a single path from input to output.

The three layers

Layer 1: Flatten

tf.keras.layers.Flatten(input_shape=(28, 28))

Flatten turns a 2D image into a 1D list. input_shape=(28, 28) is the size of one image (28 rows, 28 columns), without the batch dimension. That gives 28 × 28 = 784 pixel values.

# 3 x 3 image
[[0, 0, 255],
 [0, 255, 255],
 [255, 0, 0]]

# after Flatten
[0, 0, 255, 0, 255, 255, 255, 0, 0]

Flatten only changes shape. It learns nothing and does not change pixel values.

Layer 2: Dense with 128 neurons (hidden layer)

tf.keras.layers.Dense(128, activation='relu')

A Dense layer is fully connected: every neuron receives every output of the previous layer. Each neuron computes:

z = w1*x1 + w2*x2 + ... + wn*xn + b

x are inputs, w are weights, b is the bias, and z is the result before activation. Weights and biases are learned during training.

128 means 128 neurons. Each one learns a different weighted combination of the 784 inputs.

ReLU activation

ReLU (Rectified Linear Unit) is max(0, x): negatives become 0, positives pass through. Without a nonlinear activation, stacked Dense layers would collapse into one linear transformation. ReLU lets the network learn complex patterns.

ReLU(x) = 3

Layer 3: Dense with 10 neurons and Softmax (output layer)

tf.keras.layers.Dense(10, activation='softmax')

Ten neurons, one per digit class (0 to 9). Softmax converts the ten scores into probabilities that sum to 1. Illustrative output:

The highest probability (0.85) is digit 7, so the model predicts 7. Softmax does not guarantee the prediction is correct. It only gives relative probabilities.

  1. Receive an image with 784 pixel values.
  2. Flatten it into a 1D vector.
  3. Pass it through 128 neurons that learn useful feature combinations.
  4. Send those outputs to the ten output neurons.
  5. Apply Softmax to get a probability distribution over 0 to 9.
  6. Pick the digit with the highest probability.

Counting trainable parameters

A parameter is a weight or bias the model learns.

  • Dense (128): 784 × 128 = 100,352 weights + 128 biases = 100,480.
  • Dense (10): 128 × 10 = 1,280 weights + 10 biases = 1,290.

Training the model

The code above only defines the architecture. To learn, the model must be compiled, fitted, and evaluated.

1. Compile

model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

optimizer='adam' updates weights and biases. loss measures error for integer labels (0 to 9). metrics reports the fraction of correct predictions.

2. Fit

model.fit(train_images, train_labels, epochs=5)

epochs=5 means the model sees the full training set five times. Each pass it predicts, calculates loss, and updates its parameters.

3. Evaluate

model.evaluate(test_images, test_labels)

Checks performance on data the model was not trained on. Pixel values are commonly scaled to 0 to 1 first.

Complete code with MNIST

import tensorflow as tf

# Load the dataset
(train_images, train_labels), (test_images, test_labels) = (
    tf.keras.datasets.mnist.load_data()
)

# Normalize pixel values from 0-255 to 0-1
train_images = train_images / 255.0
test_images = test_images / 255.0

# Build the neural network
model = tf.keras.Sequential([
    tf.keras.layers.Flatten(input_shape=(28, 28)),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(10, activation='softmax')
])

# Configure training
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# Train
model.fit(train_images, train_labels, epochs=5)

# Evaluate
test_loss, test_accuracy = model.evaluate(test_images, test_labels)
print("Test Accuracy:", test_accuracy)

# Predict one test image
predictions = model.predict(test_images[:1])
predicted_digit = predictions[0].argmax()

print("Predicted Digit:", predicted_digit)
print("Actual Digit:", test_labels[0])

Actual accuracy depends on the training run and configuration.

Final summary

  1. Prepare: Flatten converts the image into 784 inputs.
  2. Learn: the 128-neuron Dense layer learns pixel combinations.
  3. Classify: the 10-neuron layer scores each digit, and Softmax turns scores into probabilities.
  4. Improve: training adjusts weights and biases to reduce errors.
Key takeaway: defining a model creates its architecture. Training is what teaches it the link between images and their correct digits. Think of a student: the image is the question, the hidden layer learns patterns, the output layer answers, and training gives examples and feedback.
